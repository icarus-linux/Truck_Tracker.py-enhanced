# Truck Tracker

A Python application for tracking truck operations, built as a learning project.

## Overview

We're building a truck tracking app to monitor temperatures, routes, and status in real-time. The results can be exported to CSV or PDF formats for reporting and analysis.

This project is a journey of learning Python while developing a practical tool. It will take time, but it's pushing us to grow our skills and problem-solving abilities.

## Features (In Development)
- Real-time truck tracking
- Temperature monitoring
- Route logging
- Status tracking
- CSV and PDF export capabilities

## Progress

This is an ongoing project. We're learning as we build.
